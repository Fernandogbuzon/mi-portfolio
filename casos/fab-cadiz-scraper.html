Resultados de la federación, sin copiarlos a mano.

La FAB publica partidos y clasificaciones en una web sin API. Construí un scraper para llevar esos datos a ADESA 80 y mantenerlos al día sin transcribirlos.

Ver código en GitHub ↗ Python · Playwright · PostgreSQL · GitHub Actions

Dos ritmos para un mismo trabajo.

Un proceso recorre las competiciones de noche. Otro consulta qué partidos deberían tener ya resultado y revisa solo esos grupos. Ambos corren en GitHub Actions y escriben en la base federativa que la plataforma lee por separado.

Menos trabajo repetido

Comparo un hash de los partidos de cada grupo con el último guardado. Si no ha cambiado, no vuelvo a procesarlo.

Clasificaciones calculadas

El barrido reconstruye la clasificación en Python, incluido el desempate particular, y descarta partidos de playoff que la federación deja publicados aunque no se juegan.

El fallo que me hizo cambiarlo.

Una temporada, la federación cambió los identificadores de competición. El scraper dejó de encontrar partidos, pero la ejecución terminaba en verde. Corregí las URLs, el manejo del error y la salida del proceso: si falla la extracción, GitHub Actions debe mostrar un fallo. Desde entonces sé cuándo hay que intervenir.
