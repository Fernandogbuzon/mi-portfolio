# Portfolio · Fernando García Buzón

Portfolio personal de **Fernando García Buzón**, desarrollador Full-Stack en Sevilla.
Sitio estático en **HTML, CSS y JavaScript puro** — sin dependencias ni build.

## ✨ Características

- Diseño minimalista y limpio, responsive (móvil/escritorio)
- Modo claro/oscuro (recuerda tu preferencia)
- Animaciones sutiles al hacer scroll
- Accesible y rápido (sin frameworks)

## 📁 Estructura

```
mi-portfolio/
├── index.html        # Contenido y estructura
├── css/styles.css    # Estilos y temas
├── js/main.js        # Tema, menú móvil y animaciones
└── README.md
```

## 🚀 Ver en local

No necesita instalación. Abre `index.html` en el navegador, o levanta un
servidor local:

```bash
# Opción 1: Python
python3 -m http.server 8000

# Opción 2: Node
npx serve
```

Luego entra en `http://localhost:8000`.

## 🌐 Publicar gratis (GitHub Pages)

1. Sube el repo a GitHub.
2. **Settings → Pages → Source:** rama `main`, carpeta `/ (root)`.
3. En unos minutos estará en `https://Fernandogbuzon.github.io/mi-portfolio/`.
